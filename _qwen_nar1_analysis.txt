### **NAR1 年度申报表（香港公司注册处）分析报告**

---

#### **P.1: 基本信息与呈报人资料**
**1. 页面标题/用途**  
- 中文：周年申报表  
- 英文：Annual Return  

**2. 可填写字段及其数据类型**  
| 字段标签 | 数据内容 |
|---------|----------|
| 公司名称 (Company Name) | 公司全称（中英文） |
| 商业名称（如有）(Business Name (If any)) | 业务运营用名称（可选） |
| 公司类别 (Type of Company) | 单选：私人公司、公众公司、担保有限公司 |
| 经营业务性质 (Business Nature) | 编码 + 描述（如“贸易”、“服务”等） |
| 本申报表的结算日期 (Date to which this Return is Made Up) | DD/MM/YYYY 格式 |
| 随本表格交付的财务报表所涵盖的会计期 (Period Covered by Financial Statements) | 起止日期（DD/MM/YYYY） |
| 在香港的注册办事处地址 (Address of Registered Office in Hong Kong) | 分段填写：室/楼/座、大厦、街道、区、地区（默认为“香港”） |
| 提交人资料 (Presentor's Reference) | 姓名、地址、电话、传真、电邮、档案编号 |

**3. 续页逻辑**  
- 无续页，此页为基本信息页。

**4. 特殊控件**  
- 复选框：公司类别（三选一）
- 日期输入：日/月/年格式
- 地址分段输入

**5. 注释与约束**  
- 私人公司无需填写第5项（财务报表期间）
- 所有字段需完整填写，特别是公司名称和注册地址
- “提交人资料”用于内部追踪，非必填但建议填写

---

#### **P.2: 联系方式与资本信息**
**1. 页面标题/用途**  
- 中文：电子邮件地址及联系电话  
- 英文：Email Address and Hong Kong Contact Telephone Number  

**2. 可填写字段及其数据类型**  
| 字段标签 | 数据内容 |
|---------|----------|
| 电邮地址 (Email Address) | 公司官方邮箱 |
| 香港联络电话号码 (Hong Kong Contact Telephone Number) | 国家代码+852 + 本地号码 |
| 按揭及押记 (Mortgages and Charges) | 总负债金额（截至申报日） |
| 无股本公司的成员人数 (Number of Member(s) of a Company Not Having a Share Capital) | 成员总数（仅适用于无股本公司） |
| 股本 (Share Capital) | 表格包含以下列：<br> - 股份类别（普通股/优先股等）<br> - 货币单位<br> - 已发行股份总数<br> - 总款额<br> - 已缴或视作已缴总额 |

**3. 续页逻辑**  
- 无续页，此页为独立信息页。

**4. 特殊控件**  
- 日期输入：DD/MM/YYYY
- 表格多行（最多5行），支持多种股份类别

**5. 注释与约束**  
- 有股本的公司必须填写“股本”部分
- 无股本公司填写“成员人数”
- “按揭及押记”为强制项，若无则填“0”

#### **P.3: 公司秘书（自然人）**
**1. 页面标题/用途**  
- 中文：公司秘书（自然人）  
- 英文：Company Secretary (Natural Person)  

**2. 可填写字段及其数据类型**  
| 字段标签 | 数据内容 |
|---------|----------|
| 中文姓名 | 完整中文名 |
| 英文姓名 | 姓氏 + 名字（分开填写） |
| 前用姓名 | 中文/英文曾用名 |
| 别名 | 中文/英文别名 |
| 香港通讯地址 | 分段填写：室/楼/座、大厦、街道、区、地区 |
| 电邮地址 | 个人邮箱 |
| 身分识别 | (a) 香港身份证部分号码（格式：*** *）<br>(b) 护照（签发国家/地区 + 部分号码） |
| 信托或公司服务提供者牌照 | 牌照编号 或 “无须领有牌照”（复选框） |

**3. 续页逻辑**  
- 若超过一名自然人秘书 → 使用 **续页A (Continuation Sheet A)**

**4. 特殊控件**  
- 复选框：“无须领有牌照”
- 身份证号码格式化输入（*** *）

**5. 注释与约束**  
- 必须至少有一名公司秘书
- 自然人秘书需提供身份证明
- 若为法人秘书，则跳转至P.4

### **字段命名模式总结**
- **通用命名规则**：  
  - 中文字段后跟英文翻译
  - 姓名分为“姓氏”和“名字”
  - 地址分段：室/楼/座、大厦、街道、区、国家
  - 身份证号码格式化为 `*** *`
  - 续页以字母 A-E 区分用途
- **角色区分**：  
  - 自然人 vs 法人
  - 董事 vs 秘书 vs 备任董事
- **字段一致性**：  
  - 所有人名、地址、身份信息结构一致
  - 股份信息统一为“类别”、“数量”、“金额”

---

### **整体逻辑与编程建议**
1. **动态表单设计**：根据公司类型（有股本/无股本、上市/非上市）启用不同页面。
2. **续页管理**：使用计数器跟踪 A-E 续页数量，并生成对应页面。
3. **角色判断**：自然人/法人角色决定使用哪类续页。
4. **数据验证**：确保日期格式、身份证格式、BRN格式正确。
5. **签名逻辑**：必须由董事或公司秘书签署，且日期有效。
